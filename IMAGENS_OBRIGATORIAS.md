# Imagens faltantes

O código foi configurado para buscar as imagens na mesma pasta dos arquivos HTML.

Antes de publicar no GitHub, coloque estes arquivos na raiz do projeto:

- `lidere.png`
- `eci.png`
- `somos.png`

Pelos nomes que você mostrou, esses arquivos devem existir na sua pasta local. Basta copiá-los para a raiz do repositório.
